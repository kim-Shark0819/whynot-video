# 피드백: 104 남은 이슈 1·2·3을 고친다 (Claude 결정)

104 결과는 Claude가 확인했고 좋다. 커밋 전이다. 같은 작업 트리에서 이어서 한다.

## 1. 오탐 막기(`genre_bl.detect_types`)
- **앞 경계**를 넣는다. 이름 바로 앞 글자가 한글 음절이면 찾지 않는다. 글 처음, 공백, 문장부호, 숫자, 영문 뒤에서만 찾는다.
  - 예외 접두어 표 `_PREFIX_OK = ("집착",)`. "집착광공"은 광공으로 찾는다.
  - 이것으로 "광공업", "떡대공원"이 걸리지 않는다. "떡대공원"은 뒤 경계로 막아야 하니 2번을 본다.
- **뒤쪽 제외**를 넣는다. 이름 뒤 6자 안에 다음 낱말이 시작하면 찾지 않는다.
  - 모든 이름 공통: "원"이 이름 바로 뒤 첫 글자로 붙는 경우(공원·수원)와 "업"(공업·수업).
  - 꽃수만: "놓", "자수", "무늬", "장식", "프린트", "패턴", "그림". 그래서 "꽃수를 놓은 셔츠", "꽃수 무늬"는 걸리지 않는다.
- bl-k에 위 예를 모두 더한다.
  - 찾지 않음: "꽃수를 놓은 셔츠", "꽃수 무늬 넥타이", "광공업", "떡대공원", "수원 출신 무심수아"
    - 마지막 예는 "무심수" 뒤에 "아"가 붙은 꼴이다. 뒤에 한글이 붙어도 찾는지 판단을 보고한다. 조사·서술어가 붙는 꼴("무심수다", "무심수인")은 찾아야 한다. 이름("무심수아")과 조사는 구별하지 않아도 된다. 찾는 쪽으로 두고 남은 이슈에 적는다.
  - 찾음: "집착광공이다", "그는 꽃수다", "(떡대공)", "떡대공,무심공"
- 변형 검사에도 앞 경계·뒤쪽 제외 변형을 더한다.

## 2. 103 정의 정리(승인)
- 부르는 곳이 없는 103 함수(서버 4개, 화면 4개)와 쓰지 않는 CSS 선택자를 지운다. Claude가 승인했다.
- 지운 정의를 결과 보고에 나열한다. 검사가 그 정의를 직접 부르고 있으면 그 부분만 함께 정리한다.

## 3. 맞지 않게 된 주석
- `app/src/vnew/settings.py`, `deploy/config.env.example`, `k8s/workloads.yaml.tmpl`의 `VNEW_BL_LOOK` 주석을 "캐릭터 설명(추가 요청)에 적힌 BL 유형을 참고 문장으로 더한다"는 뜻으로 고친다. 주석만 고치고, 값과 자리는 그대로 둔다.
